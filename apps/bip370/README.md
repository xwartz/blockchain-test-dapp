# BIP-370 Test DApp

A standalone React application for testing BIP-370 PSBT (Partially Signed Bitcoin Transaction) functionality.

## Features

- BIP-370 PSBT creation and manipulation
- Bitcoin transaction building
- PSBT signing and verification
- Modern UI with Tailwind CSS and Shadcn UI

## Development

```bash
# Install dependencies
pnpm install

# Start development server (runs on port 3002)
pnpm dev

# Build for production
pnpm build

# Run linting
pnpm lint
```

## Usage

1. Start the development server
2. Open http://localhost:3002 in your browser
3. Test BIP-370 PSBT functionality

## Dependencies

- React 18
- TypeScript
- Vite
- Tailwind CSS
- bitcoinjs-lib
- Various Bitcoin-related libraries
