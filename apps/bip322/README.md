# BIP-322 Test DApp

A standalone React application for testing BIP-322 message signing functionality.

## Features

- BIP-322 message signing and verification
- Bitcoin address validation
- Modern UI with Tailwind CSS and Shadcn UI

## Development

```bash
# Install dependencies
pnpm install

# Start development server (runs on port 3001)
pnpm dev

# Build for production
pnpm build

# Run linting
pnpm lint
```

## Usage

1. Start the development server
2. Open http://localhost:3001 in your browser
3. Test BIP-322 message signing functionality

## Dependencies

- React 18
- TypeScript
- Vite
- Tailwind CSS
- bitcoinjs-lib
- Various Bitcoin-related libraries
