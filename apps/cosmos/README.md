# Cosmos Test DApp

A standalone React application for testing Cosmos blockchain functionality and wallet integration.

## Features

- Cosmos wallet connection (Keplr, Leap)
- Cosmos transaction signing and broadcasting
- Chain registry integration
- Interchain UI components
- Modern UI with Tailwind CSS and Shadcn UI

## Development

```bash
# Install dependencies
pnpm install

# Start development server (runs on port 3003)
pnpm dev

# Build for production
pnpm build

# Run linting
pnpm lint
```

## Usage

1. Start the development server
2. Open http://localhost:3003 in your browser
3. Connect your Cosmos wallet (Keplr or Leap)
4. Test Cosmos blockchain functionality

## Dependencies

- React 18
- TypeScript
- Vite
- Tailwind CSS
- @cosmos-kit/react
- @cosmjs libraries
- @interchain-ui/react
- chain-registry
